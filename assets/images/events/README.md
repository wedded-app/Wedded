# Event photos

One photo per event slug (`src/features/home/event-photos.ts`): beside each
event on Home's Plan by event, and across the top of the event's guide
(`/e/[slug]`). Each is a 900 × 675 JPEG cropped from a free Pexels photo (the
[Pexels licence](https://www.pexels.com/license/) allows use in an app without
credit; listed here so we can find them again). Several are the same photos
as the category photos in `assets/images/kinds/`, larger. An event with no
photo shows its emoji instead.

Once vendors have real photos, and the database can take a picture per event
after the demo, these should move there.
