# Event photos

The photos beside each event on Home's Plan by event
(`src/features/home/event-photos.ts`), one per event slug. Most events reuse
a category photo from `assets/images/kinds/`; these four are their own. Each is
a 288 × 288 JPEG cropped from a free Pexels photo (the
[Pexels licence](https://www.pexels.com/license/) allows use in an app without
credit; listed here so we can find them again). An event with no photo shows
its emoji instead.
