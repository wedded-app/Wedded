# Category photos

The round photos on the Vendors tab's Browse categories and on All categories
(`src/features/search/kind-photos.ts`), one per category slug. Each is a
288 × 288 JPEG cropped from a free Pexels photo (the
[Pexels licence](https://www.pexels.com/license/) allows use in an app without
credit; listed here so we can find them again). A category with no file here
shows its group's icon instead.

Once vendors have real photos, and the database can take a picture per
category after the demo, these should move there.
